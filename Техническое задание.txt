ТЕХНИЧЕСКОЕ ЗАДАНИЕ

Контекст:
В Учебном центре временно недоступны основные каналы связи (технические работы на корпоративных почтовых серверах), а также действует гибкая система скидок на курсы. Вам необходимо реализовать логику расчета стоимости со скидками и один API-эндпоинт для обработки заявок.

Технический стек:
.NET 6 / 8, ASP.NET Core Web API. Использовать реальную СУБД или настраивать Docker не нужно — достаточно InMemory-коллекции, Mock-данных или работы в оперативной памяти.

Задача 1. Логика расчета скидок (Backend)

Реализуйте метод/сервис, который принимает список курсов и статус пользователя, а возвращает итоговую стоимость корзины.

«Горящие группы»: Если до старта курса осталось менее 5 дней, на него автоматически применяется скидка 20%.
«Выпускник»: Если у пользователя в профиле стоит флаг IsGraduate = true, на курсы применяется скидка 30%.
Правило бизнеса: Скидки не суммируются. Для каждого курса должна выбраться только одна — максимальная из доступных скидок.
Задача 2. Отказоустойчивый контроллер (POST /api/leads)

Реализуйте эндпоинт для отправки формы «Обратный звонок».

Входные данные (DTO): Имя, Телефон, Email, Тип клиента (Физ. лицо / Юр. лицо).
Штатная логика: Метод должен вызвать условный сервис отправки почты.
Отказоустойчивость: Имитируйте сбой (исключение) основного почтового сервиса. Контроллер должен перехватить ошибку и перенаправить заявку на резервный email:
Если клиент Юр. лицо → на specialist.corp@yandex.ru
Если клиент Физ. лицо → на specialist.ufl@yandex.ru
Пользователь на сайте должен получить успешный ответ 200 OK, не замечая внутреннего сбоя.
 

Критерии оценки и формат сдачи:

Архитектура: Использование асинхронности (async/await), правильное разделение на контроллер и сервисный слой через Dependency Injection (DI).
Валидация: Проверка входных данных (валидный Email, заполненный Телефон).
Тесты: Наличие 2-3 Unit-тестов (например, на xUnit)
Формат: Код необходимо загрузить в Ваш личный публичный репозиторий на GitHub или GitLab и прислать ссылку ответным письмом. Доступы к нашей действующей инфраструктуре для выполнения задания не требуются.

Важно: Финальным этапом проверки станет короткое онлайн-интервью (технический созвон), на котором мы попросим Вас кратко рассказать об архитектуре Вашего решения и ответить на несколько вопросов по написанному коду.

Ориентировочный срок выполнения: 2–3 дня. Будем ждать от Вас обратную связь по готовности.
